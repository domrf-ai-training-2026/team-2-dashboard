# Команда 2. Воронка продаж

На каком этапе теряются потенциальные сделки?

Все данные вымышлены. Это учебный проект, не официальный сервис ДОМ.РФ.

## Что нужно сделать

Фильтры по неделе, офису и продукту; график этапов воронки; конверсии; проблемные офисы; сервисные показатели из API команды 3.

1. Скачайте source.csv и с помощью Qwen, Deepseek, GigaChat или DeepSeek Harness создайте собственный index.html. Опишите моделью единицы и формулы, проверьте значения. Текущий index.html — пример тренера; участники собирают свою версию.
2. Проверьте файл в браузере через локальный сервер. Добавьте минимум 2 графика, 4 показателя, таблицу, фильтры, кнопку обновления и сообщение об ошибке источника.
3. Загрузите свою версию в свой репозиторий (или назначенный репозиторий команды с доступом Write). В GitHub: Add file → Upload files → Commit changes. Не создавайте и не передавайте токены другим командам.
4. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Дождитесь успешной публикации и проверьте страницу по ссылке Pages.
5. Преобразуйте source.csv в data.json по контракту API.md и опубликуйте его в своём репозитории. Каждый раз обновляйте updated_at. Откройте JSON по публичному адресу Pages, не по ссылке github.com/blob.
6. **Выставьте свой API другой команде:** передайте ей URL вашего data.json, единицы, ключи period/office_id, пример ответа и описание полей. Адреса фиксируйте в таблице обмена у тренера. Если работаете в форке, передайте фактический адрес вашего Pages.
7. Подключите API команды 3 к своему дашборду через fetch. Покажите рядом с конверсией долю повторных визитов из API команды 3. Корреляция не доказывает причину. Используйте общие ключи period и office_id; сначала агрегируйте продуктовые строки, чтобы не умножить данные при объединении.
8. **Проверьте обмен:** владелец меняет число в своём data.json и публикует commit; сосед дожидается Pages deploy, нажимает Обновить и показывает новое значение. Скачанная копия JSON или вшитые значения не засчитываются.

## Формулы

Этапы одной завершённой учебной когорты отнесены к неделе выдачи. Конверсия = сумма выдач / сумма лидов. Лиды ≥ заявки ≥ одобрения ≥ выдачи.

## Контроль

Для 2026-11-06, A01, Ипотека: 136 лидов, 96 заявок, 71 одобрение, 53 выдачи; конверсия 38,97%.

## Что сдать

Ссылку на свою страницу, репозиторий и API; адрес подключённого API другой команды; скриншоты до/после изменения; 2 предложения о полученном управленческом выводе.

GitHub Pages здесь публикует статический JSON по HTTP GET. Это учебный API для чтения: POST, запись в файл с клиента, серверные секреты и вызовы платных ИИ-API на Pages не реализованы. Обмен идёт адресами и данными, не секретными API-ключами.
